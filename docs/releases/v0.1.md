Prototype for the user study (Step 4).

**Live app:** https://hyao8.github.io/706_prototype/

An interactive explorer for the Orphadata rare-disease knowledge base (July 2026 release, full dataset:
10,101 active entities, 4,623 genes, 8,758 HPO signs). Built with JavaScript, D3 and Vite; no server.

## What is in this release

- **Overview:** disorders per specialty, the largest specialty overlaps, prevalence classes per specialty, and a
  candidate list ranked by clinical signs (tasks T1, T4, T6).
- **Disease:** profile with prevalence, age of onset, inheritance, genes and signs, and a sign comparison matrix
  (tasks T2, T5).
- **Gene:** ranked genes, a gene–disease graph with a matrix view, and specialty bars (task T3).
- One filter panel and one selection shared by all pages; a selection bar shows what is selected.
- The view is stored in the address, so links can be shared and the Back button works.
- In-app guide, search shortcut (`/`), keyboard access to the charts.

The study tasks and their expected answers are in `docs/study_plan.md`. To run the app locally, see `README.md`.
The attached zip holds the built site (`dist/`); serve it with any static file server.
